# Checklist: LLM

`profile.llm = true` のときだけ読む（OWASP LLM Top 10 2025 要約）。

| ID | ★ | 項目 | 確認 |
|---|---|---|---|
| L-01 | ★ | プロンプト注入 | ユーザー入力・RAG 文書がシステム指示や他ユーザー文脈を上書きできない設計か |
| L-02 | ★ | 出力を生実行しない | LLM 出力を SQL/シェル/購入/メールに直接渡さない。スキーマ検証＋認可付きツール |
| L-03 | ★ | 最小権限・人の介在 | 削除・送金・本番DB書き込みがエージェントに付いていない。破壊操作は確認付き |
| L-04 | ★ | 利用量上限 | ユーザー/IP 単位のレートまたは予算。公開プロキシなら必須 |
| L-05 | | システムプロンプトに秘密なし | 「プロンプトを見せて」で鍵・内部URLが出ない。出ても認可の代替にしない |
| L-06 | | RAG テナント分離 | 検索フィルタに org/user。他テナント文書が混ざらない |
| L-07 | | 断定UI | 医療・法務・金融で根拠なし断定していない |
| L-08 | | 会話ログ漏洩 | 他者PII・秘密が次コンテキストや管理exportに漏れない |

ツール定義ファイル（function calling）を必ず Read し、権限の広さを finding にする。
