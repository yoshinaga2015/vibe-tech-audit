## 2026-08-18 — README 体裁刷新（EN / JA）

### 変更の具体

- `README.md` / `README.ja.md` 先頭に Docs EN/JP 切替バッジを追加（表示中言語を強調色）
- 中央寄せヒーロー（タグライン・姿勢・バッジ列・ページ内ナビ）
- Modes / adversarial / 否定リストを表と固定幅フローで整理
- リポジトリ構成図のルート表記を `publish/` から `.` に修正（GitHub ルートと一致）

### 意図

GitHub ランディングとして、言語切替とスキルの価値提案を一瞬で伝え、中身の契約（証拠必須・報告ファースト・fix は明示時のみ）を視覚的に固定する。

### ADR

- **Decision:** README の視覚言語は slate + sky の shields バッジに統一し、言語切替は右上 for-the-badge、メタ情報は flat-square とする。
- **Why:** セキュリティ系ツールの「暗い・実務的」トーンを保ちつつ、言語切替を見落とさないコントラストを取る。
- **Rejected:** 絵文字だらけのヒーロー、紫グラデ系テンプレ、本文冒頭のプレーン「日本語 README」リンクのみ（重複・弱い）。
- **Consequence:** shields.io 依存（オフライン表示時はバッジ画像が欠けるが、リンク文言は残る）。
